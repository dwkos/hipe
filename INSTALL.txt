HIPE INSTALLATION SUMMARY

The three parts are built in this order. Each directory has fuller notes, and the
Installation section of the manual (https://hipe.generaldevelopment.net, or the archived
copy in manual.html) explains how to set Hipe up to run.

Hipe builds with Qt 5.15 or Qt 6. Earlier Qt 5 releases are not supported. Build the display
engine and the display server with the same Qt version: only one copy of the engine can be
installed at a time.

Qt 6 support is new. The test suites pass with Qt 6.8, but these have not been tried on Qt 6
yet: touch and mouse-wheel input from real devices, the clipboard, input methods, video
playback, embedded X11 windows, high-DPI screens, and running natively under Wayland.


1. BUILD AND INSTALL THE DISPLAY ENGINE (hipecore)
==================================================

hipecore is built with CMake and Ninja. See hipecore/README.md for its dependencies.

$ cd hipecore
$ mkdir build && cd build
$ cmake -G Ninja -DPORT=Qt -DCMAKE_BUILD_TYPE=Release ..
$ ninja
$ sudo ninja install

For Qt 6, add -DHIPECORE_QT_MAJOR=6 to the cmake command.

This installs the libraries libHipeCore and libHipeCoreWidgets, and their headers in
/usr/include/HipeCore. hipecore has its own names, so it can be installed on a system
that also has Qt5WebKit.


2. BUILD THE DISPLAY SERVER (hiped)
===================================

The server is a Qt application built with qmake. See server/README.txt for its
dependencies and for the ways it can be run.

$ cd server
$ qmake -makefile ./src/hiped.pro
$ make

For Qt 6, run qmake6 in place of qmake.

This produces the hiped executable in the server directory. Copy it wherever you like,
for example /usr/local/bin/.


3. BUILD AND INSTALL THE CLIENT LIBRARY (libhipe)
=================================================

The client library is an ordinary C library with minimal dependencies. See api/INSTALL.txt
if your system doesn't use /usr/local/.

$ cd api
$ make
$ sudo make install


4. TRY IT
=========

Build the sample applications, start the display server, and run one of them:

$ cd api
$ make testing
$ ../server/hiped &
$ ./test/hipe-clock

A window with a digital clock should open. The samples' source code, in api/test/, is the
quickest way to see how a Hipe application is written.
